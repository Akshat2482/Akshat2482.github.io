Watch the live distance above while the door is closed, then set the threshold a few cm higher than that reading. Any distance at or below the threshold reports as "closed"; anything further away reports as "open." Saves permanently to the board's flash memory -- no reflashing needed. Requires Chrome or Edge -- Web Bluetooth is not supported in Safari on iPhone/iPad.
